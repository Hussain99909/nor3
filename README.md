# بلوك كراش: النسخة المطوّرة

نسخة أندرويد 3.0.0 أضيفت إلى المشروع، مع معاينة أثناء السحب، ومؤثرات مسح، وأزرار وأيقونة محسّنة، واهتزاز اختياري، وحفظ محلي، وقائمة استراحة مرتبطة بزر الرجوع. تعليمات التثبيت والبناء في `ANDROID.md`. نسخة HTML تبقى مستقلة بالإصدار 2.0.0.

لعبة بلوكات عربية مناسبة للهاتف، مستوحاة من الملف المرجعي. اللعب بالسحب والإفلات فقط: النقر على اللوحة أو مرور المؤشر فوقها لا يعرض قطعة ولا يضعها. تظهر معاينة المكان أثناء سحب قطعة فعلياً، والإفلات غير الصالح يعيد القطعة إلى مكانها. إكمال صف أو عمود يزيله ويمنحك نقاطاً وكريستالات.

النسخة الثانية تحتوي لوحة أكبر بإطار رفيع، وقطع احتياطية أكبر، ومجسمات سميكة بحواف لامعة وألوان واضحة، وخلفية جديدة هادئة. تم الاحتفاظ بمفتاح حفظ النسخة السابقة حتى يبقى تقدم اللاعب محفوظاً على نفس الجهاز والمتصفح.

## التشغيل

افتح `index.html` بمتصفح Chrome أو Edge أو Safari حديث يدعم WebGL. الملف يحتوي الرسومات والموديلات والمكتبات داخله ويعمل دون إنترنت ودون خادم. على الهاتف انقل الملف وافتحه بمتصفح يدعم فتح ملفات HTML المحلية، أو ارفع الملف إلى استضافة HTTPS.

يوجد 24 مستوى في ثلاثة عوالم، ووضع لعب حر، وتراجع، وتدوير، وقنبلة، وشراء قطع، وأصوات، وإعداد جودة الرسومات. الحفظ محلي على نفس الجهاز والمتصفح؛ وضع التصفح الخاص أو حذف بيانات المتصفح قد يمسح التقدم. إذا احتجت الرجوع إلى المستويات استخدم زر الخريطة.

## Unity

افتح مجلد `UnityProject` من Unity Hub باستخدام Unity 6000.6.4f1 أو نسخة متوافقة من Unity 6. افتح المشهد `Assets/Scenes/CrystalGarden.unity` واضغط Play. مشروع Unity يحتوي كود C#، و24 مرحلة، وموديل OBJ مع حواف ناعمة، وصورة البيئة، ونصوص عربية مرسومة كصور لضمان اتصال حروفها.

**نسخة HTML المرفقة مستقلة ومبنية باستخدام Three.js؛ ليست تصديراً من Unity.** تم إنشاء وفحص مشروع Unity فعلياً بالمحرر الموجود على الجهاز. إضافة WebGL Build Support غير مثبتة في هذا المحرر، لذلك لا تتضمن الحزمة نسخة Unity WebGL مجمعة. بعد تثبيت الإضافة من Unity Hub يمكنك استخدام قائمة `Crystal Blocks > Build WebGL` لتصدير المشروع. راجع [دليل بناء Unity](https://docs.unity.com/en-us/engine/6000.6/manual/building-and-publishing/build-customize-build-pipeline/build-command-line).

لبناء أندرويد من المشروع، استخدم `Crystal Blocks > Build Android APK` أو ملف `BuildAndroid.ps1`. بناء APK لا يحتاج إضافة WebGL.

## الملفات

- `index.html`: اللعبة المستقلة الجاهزة.
- `assets/blocks.glb`: ستة بلوكات ثلاثية الأبعاد مع رموز تميّز ألوانها؛ الموديل مستخدم فعلياً داخل نسخة المتصفح.
- `assets/toy-studio-v2.png` و`toy-studio-v2.jpg`: الخلفية الجديدة ونسخة مناسبة للويب.
- `assets/levels.json`: بيانات الأشكال والمستويات.
- `Source`: مصادر نسخة المتصفح، للتعديل وإعادة التجميع.
- `UnityProject`: مشروع Unity والمشهد والموارد.
- `preview-*.png`: صور فحص الشاشة والمرحلة المكتملة.
- `VERIFICATION.txt`: نتائج الفحص وحدوده.

لتعديل نسخة المتصفح، افتح مجلد `Source`، ثبّت المتطلبات باستخدام `npm install` ثم شغّل `npm run build`. إعادة التجميع تحدث `index.html` وتضمّن الرسومات والموديلات من مجلد `assets` مجدداً.

الخلفية الجديدة أُنشئت بأداة imagegen المدمجة؛ وصفها محفوظ في `assets/art-prompt.txt`. موديلات البلوكات والرموز الهندسية أُنشئت لهذه اللعبة. تراخيص Three.js وLucide موجودة في `assets`. ملف المستخدم المرجعي بقي دون تعديل. لا يوجد ربط سحابي أو Firebase يحتاج مفاتيح إعداد.
